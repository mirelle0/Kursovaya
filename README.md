# Курсовой проект

# Вариант 28. Мониторинг реактора: активность катализатора.

## Постановка задачи

Разработать программу на языке Си для мониторинга реактора, которая вычисляет показатель активности катализатора (Q) на основе введенного пользователем значения (X). В зависимости от диапазона X (до 65, от 65 до 90, или выше 90) расчет Q производится по одной из трех заданных математических формул.
